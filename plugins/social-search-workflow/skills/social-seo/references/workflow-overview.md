# 社交媒体搜索指数工作流 — 全局设计文档

## 工作流概述

本工作流以**搜索指数**为核心KPI，覆盖小红书和抖音/微信视频号平台，
将内容投放的全生命周期拆解为六个节点，形成数据驱动的闭环。

## 节点详解

### 节点① 选题挖词
**目标**：找到搜索量大、竞争度适中、与品牌相关的关键词

**输入**：品牌名、产品信息、竞品名单

**动作**：
- 在小红书/抖音搜索框输入品牌词，记录联想词
- 分析TOP20竞品内容的标题关键词
- 构建五层关键词矩阵（品牌词→品类词→场景词→竞品词→趋势词）
- 评估每个词的：搜索量级 / 内容竞争度 / 与品牌的关联度

**输出**：关键词矩阵 + 优先级排序

**工具**：`/keyword-research <品牌名>`

---

### 节点② 内容策划
**目标**：基于关键词矩阵设计内容组合，制定发布节奏

**输入**：关键词矩阵、历史内容数据（如有）

**动作**：
- 为每个目标词设计对应内容类型（测评/教程/种草/对比/剧情）
- 制定一周/月度内容日历，分配关键词到具体内容
- 设计内容间的关联性（合集/系列，叠加权重）
- 规划KOL/KOC联动布局（扩大搜索触达）

**输出**：内容策划单（标题、大纲、关键词布局、发布时间）

**工具**：`/content-brief <品牌名>`

---

### 节点③ 内容创作
**目标**：产出符合搜索优化要求的内容素材

**小红书图文创作规范**：
```
封面：核心词文字 + 高辨识度视觉
标题：核心词前置 + 利益点/数字/情绪词
正文：
  - 开头100字：核心词 + 痛点场景
  - 主体：分点展开，自然嵌入关键词
  - 结尾：引导评论（包含关键词引导语）
话题：大词 + 中词 + 精准词（共3-5个）
```

**抖音/视频号视频创作规范**：
```
首帧：高光画面 + 文字关键词
口播前3秒：必含核心关键词
字幕：全程字幕，确保OCR抓取准确
脚本节奏：钩子(3s) → 背景(12s) → 主体(30s) → 高光(15s) → CTA(5s)
文案：前50字含2-3个核心词
```

**工具**：调用 content-optimizer 代理优化文案

---

### 节点④ 发布执行
**目标**：在最优时机发布内容，最大化初始流量获取

**发布时间参考**：
| 平台 | 最佳时段 | 次优时段 |
|------|---------|---------|
| 小红书 | 晚8-10点 | 午12-1点 |
| 抖音 | 晚7-9点 | 午11-12点 |
| 视频号 | 晚8-10点 | 早7-9点 |

**发布频次建议**：
- 小红书：每天1条（稳定）或每周3-5条（高强度）
- 抖音：每天1-2条
- 视频号：每天1条（关联朋友圈预热）

**发布后1小时必做**：
1. 置顶评论 — 补充关键词，引导互动
2. 首轮互动 — 回复早期评论，触发推流
3. 搜索收录确认 — 搜索核心词，确认内容出现

**工具**：`/publish-checklist <内容标题>`

---

### 节点⑤ 搜索优化（持续运营）
**目标**：通过持续运营维持和提升搜索权重

**日常运营动作**：

```
每日：
□ 查看内容的搜索流量占比（目标：搜索流量>30%）
□ 回复评论中出现的关键词相关问题
□ 观察竞品新发内容，更新关键词策略

每周：
□ 检查核心词在平台的搜索结果排名
□ 对高搜索流量内容进行二次推广（小红书付费推广）
□ 更新关键词日历，补充新词

每月：
□ 搜索指数数据汇总
□ 竞品搜索份额对比
□ 内容类型ROI分析（哪类内容搜索贡献最高）
```

**评论区关键词运营**：
- 在评论区引导用户提及目标关键词
- 对提及关键词的评论优先置顶回复
- 创建关键词相关的话题引导（"你会怎么用[关键词]？"）

---

### 节点⑥ 复盘归因
**目标**：数据驱动优化下一轮策略

**搜索指数复盘维度**：

```
1. 指数趋势分析
   - 环比/同比变化幅度
   - 与内容发布节点的关联
   - 是否出现脉冲上升（爆款效应）

2. 词组结构分析
   - 品牌词搜索量占比
   - 品类词搜索量占比
   - 长尾词覆盖广度

3. 内容贡献归因
   - 哪条内容发布后搜索指数最明显上升
   - 该内容的特征（类型/关键词/形式）
   - 可复制的规律提炼

4. 竞品对比
   - 竞品搜索指数变化
   - 市场搜索份额的相对变化

5. 下期策略调整
   - 加大投入：哪类内容/关键词效果好
   - 减少投入：哪类内容/关键词无效
   - 新机会：哪些词有上升趋势但未布局
```

**复盘输出模板**：
```markdown
## [月份] 搜索指数复盘

### 本月结果
- 搜索指数：[数字] → [数字]（变化：+X%）
- 品牌词指数：[数字]
- 品类词搜索份额：[X]%

### 关键事件
- [日期]：发布[内容]，搜索指数上升[X]%（爆款效应）
- [日期]：[其他关键节点]

### 内容效果排名（搜索贡献）
1. [内容标题] — 贡献搜索指数提升 [X]%
2. ...

### 下月策略调整
- 继续：[有效策略]
- 调整：[无效策略] → 改为 [新策略]
- 新布局：[新词/新形式]
```

## 搜索指数里程碑参考

| 阶段 | 搜索指数量级 | 特征 | 关键动作 |
|------|------------|------|---------|
| 冷启动 | <1000 | 几乎无搜索基础 | 铺量品牌词内容，建立基础权重 |
| 成长期 | 1000-1万 | 有基础搜索流量 | 扩展品类词，布局KOL联动 |
| 爆发期 | 1万-10万 | 搜索进入良性循环 | 冲击竞品词，话题事件借势 |
| 成熟期 | >10万 | 搜索指数稳定 | 维护+精细化运营，防御竞品 |

## 快速参考：内容类型 × 搜索指数贡献

| 内容类型 | 对搜索指数的贡献方式 | 适合阶段 |
|---------|-------------------|---------|
| 测评/真实体验 | 触发用户搜索品牌词，信任度高 | 全阶段 |
| 教程/攻略 | 长尾词覆盖，搜索留存时间长 | 成长期+ |
| 对比/竞品 | 截流竞品搜索用户 | 成长期+ |
| 剧情/趣味 | 短期搜索脉冲，带动品牌词 | 爆发期 |
| 合集/盘点 | 覆盖多个关键词，搜索权重叠加 | 全阶段 |
| KOL种草 | 粉丝带动品牌词搜索量 | 成长期+ |
