# 社交平台搜索优化技能

当用户讨论社交媒体搜索相关话题时，始终参考以下框架作答。

## 搜索指数核心逻辑

搜索指数 = 平台上用户主动搜索某词的相对热度。提升搜索指数的本质：
**让更多用户产生搜索你品牌/产品关键词的动机。**

提升路径：
```
内容触达用户 → 用户产生兴趣/需求 → 用户主动搜索相关词 → 搜索指数上升
                                   ↑
                         内容中关键词引导 + 评论区关键词运营
```

## 小红书搜索权重因素（重要性排序）

1. **标题关键词**（权重最高）：核心词必须在前10字
2. **正文关键词密度**：核心词3-5次，分布自然
3. **话题标签**：大词引流 + 精准词转化
4. **互动数据**：收藏 > 评论 > 点赞（对搜索权重影响）
5. **评论区关键词**：用户在评论中提及目标词，会加强该词的关联权重
6. **内容完整度**：字数300字以上，图片8张以上，权重更稳定

## 抖音/视频号搜索权重因素

1. **视频标题**：前15字含核心词
2. **文案前50字**：核心词出现1-2次
3. **字幕/口播**：前3秒口播含核心词（系统OCR抓取）
4. **话题标签**：3-5个，覆盖大中小词
5. **完播率和互动**：间接影响搜索权重
6. **账号垂直度**：持续发布同类内容，账号标签强化

## 话题标签选择原则

| 类型 | 目的 | 数量 |
|------|------|------|
| 品牌词话题 | 品牌搜索聚合 | 1个 |
| 品类大词话题 | 引入大流量 | 1-2个 |
| 场景/人群精准词 | 精准用户转化 | 1-2个 |
| 趋势热点话题 | 借势短期流量 | 0-1个（可选） |

## 搜索指数复盘的四个维度

1. **词量分析**：品牌词/品类词/长尾词各占多少搜索量
2. **趋势分析**：搜索指数是否随内容发布出现脉冲式上升
3. **竞品对比**：与竞品的搜索份额变化趋势
4. **内容归因**：哪类内容（测评/教程/种草/对比）对搜索指数贡献最大
