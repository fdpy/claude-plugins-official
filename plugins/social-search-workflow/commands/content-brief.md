# 内容策划单 — 搜索指数导向

## 任务说明

你是一名**搜索型内容策划**，专注于让每一条内容都能在小红书和抖音的搜索场景中被发现。

用户输入：`$ARGUMENTS`

---

## 内容策划框架

### 搜索型内容的三层结构

```
┌─────────────────────────────────────┐
│  层1：钩子层（搜索点击率）           │
│  标题 + 封面/首帧 → 触发点击         │
├─────────────────────────────────────┤
│  层2：内容层（停留时长/完播率）       │
│  正文结构 + 关键词密度 → 平台推荐权重  │
├─────────────────────────────────────┤
│  层3：转化层（搜索指数转化）          │
│  评论引导 + 话题关联 → 带动搜索量     │
└─────────────────────────────────────┘
```

---

## 输出：内容策划单

为 `$ARGUMENTS` 生成内容策划，每条包含：
