# 发布前检查 — 搜索指数最优化

## 任务说明

你是一名**社交媒体SEO审核员**，在内容发布前做最后一道质量关卡。

待检查内容：`$ARGUMENTS`

---

## 通用检查项（平台无关）

### ✅ 关键词检查
- [ ] 核心关键词出现在标题前10字
- [ ] 正文关键词自然分布（无堆砌感）
- [ ] 话题标签数量合理（小红书3-5个，抖音3-8个）
- [ ] 话题标签包含：大话题（>1亿浏览）+ 中话题（1千万-1亿）+ 精准小话题
- [ ] 无违禁词、敏感词（平台限流风险）

### ✅ 内容质量检查
- [ ] 标题有明确的搜索意图对应（用户搜什么，标题给什么）
- [ ] 内容满足用户搜索该词的核心需求
- [ ] 有清晰的结构（问题→解决→结论）
- [ ] 结尾有引导用户互动/搜索的CTA

### ✅ 账号健康检查
- [ ] 今日未超发（小红书建议≤1条/天，抖音≤3条/天）
- [ ] 上一条内容已获得基础互动再发布
- [ ] 账号近期无违规记录

---

## 小红书专项检查

### 图文笔记
- [ ] 封面图文字清晰，手机端缩略图可读
- [ ] 封面包含核心关键词（视觉文字）
- [ ] 图片比例：3:4（推荐）
- [ ] 正文字数：300-1000字（搜索权重最优区间）
- [ ] 正文中关键词出现3-5次（自然语境）
- [ ] 末尾有引导评论的问题（如"你们有试过xxx吗？"）
- [ ] 地理位置标签已设置（本地内容必须）

### 搜索指数专项
- [ ] 标题已在小红书搜索框测试，确认有相关联想词
- [ ] 核心词搜索结果前20条已分析，差异化角度明确
- [ ] 内容发布后计划在评论区第一条补充关键词

---

## 抖音 / 微信视频号专项检查

### 视频
- [ ] 视频时长在平台推荐区间（抖音：60-180s；视频号：1-3min）
- [ ] 前3秒出现核心关键词（口播或字幕）
- [ ] 字幕准确，无错别字（影响字幕抓取权重）
- [ ] 视频描述前50字包含2-3个核心关键词
- [ ] 封面为视频高光帧，文字清晰
- [ ] BGM版权安全（使用平台授权音乐库）

### 发布设置
- [ ] 视频号：已同步朋友圈预热（可选）
- [ ] 抖音：已添加到合集（提升系列权重）
- [ ] POI地点标签已设置（本地类内容）

## 发布后 1 小时必做

```
□ 置顶评论：补充 1-2 个关键词引导评论
  示例："想了解更多关于[关键词]的，评论区告诉我～"

□ 自评区互动：对前5条评论做回复，触发平台推流

□ 搜索验证：在平台搜索核心词，确认笔记/视频已被收录

□ 数据埋点：记录发布时间、初始搜索指数，用于复盘对比
```
