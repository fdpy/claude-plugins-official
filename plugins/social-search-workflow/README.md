# social-search-workflow

以**搜索指数**为核心KPI的社交媒体内容投放工作流插件，覆盖小红书和抖音/微信视频号平台。

## 工作流六节点

```
选题挖词 → 内容策划 → 内容创作 → 发布执行 → 搜索优化 → 复盘归因
    ↑                                                          |
    └──────────────────── 数据反馈 ────────────────────────────┘
```

## 组件

### 斜杠命令

| 命令 | 作用 |
|------|------|
| `/keyword-research <品牌名>` | 关键词挖掘，输出五层关键词矩阵 |
| `/content-brief <品牌名>` | 生成一周内容策划单（标题、大纲、关键词布局） |
| `/publish-checklist <内容标题>` | 发布前SEO检查，输出就绪评分 |

### 代理

| 代理 | 模型 | 作用 |
|------|------|------|
| `search-strategist` | Opus | 整体搜索指数增长策略、竞品分析、复盘归因 |
| `content-optimizer` | Sonnet | 对已有内容进行SEO优化，输出改前/改后对比 |

### 技能（自动激活）

当对话中出现搜索指数、小红书SEO、抖音搜索、关键词布局等词汇时，自动注入搜索优化最佳实践参考。

## 快速开始

```
# 1. 挖掘关键词
/keyword-research 你的品牌名

# 2. 生成内容策划
/content-brief 你的品牌名

# 3. 发布前检查
/publish-checklist 内容标题

# 4. 需要整体策略时
调用 search-strategist 代理

# 5. 需要优化已有文案时
调用 content-optimizer 代理，粘贴原始文案
```

## 搜索指数提升原理

搜索指数上升的核心路径：

```
内容触达用户 → 激发兴趣/需求 → 用户主动搜索关键词 → 搜索指数上升
                                ↑
                    内容中关键词布局 + 评论区关键词运营
```

本插件从选题到复盘，全流程以这条路径为中心设计。

## 平台覆盖

- **小红书**：图文笔记SEO，权重因素：标题>正文>话题>互动>评论区
- **抖音**：短视频SEO，权重因素：标题>文案前50字>字幕口播>话题>完播率
- **微信视频号**：同抖音逻辑，额外考虑朋友圈预热和社交裂变
